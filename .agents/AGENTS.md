# Project Rules — Rajhans Tea

## UI-Only Editing Rule

The developer on this project is a beginner working on an existing codebase.

**Unless explicitly asked otherwise, only modify `.html` and `.scss` files.**

Do NOT edit any of the following without explicit user permission:
- `.ts` or `.js` files (Angular components, services, stores, guards, etc.)
- Backend code (Node.js, Express, controllers, routes, middleware)
- APIs or API endpoints
- Business logic or data processing
- Routing configuration
- Environment files (`.env`, `environment.ts`, `environment.prod.ts`)
- Build or configuration files (`angular.json`, `package.json`, `tsconfig.json`, etc.)

**Preserve all existing behavior.** Only change UI layout, visual styling, and HTML structure.

If a requested UI change would require modifying logic or `.ts` files to implement correctly, **explain why** instead of making the change.
